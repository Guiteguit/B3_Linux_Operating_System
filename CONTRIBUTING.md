# Contribuer

Les contributions sont bienvenues lorsqu'elles améliorent le support sans révéler les corrections du cours.

## Contributions adaptées au dépôt public

- correction d'une faute ou d'une commande obsolète ;
- amélioration d'une explication ;
- compatibilité avec une version Ubuntu plus récente ;
- amélioration non triviale d'un validateur ;
- ajout d'un challenge qui ne révèle pas le Final Boss.

## À ne pas publier ici

- solutions complètes des TPs ;
- scripts d'injection du Final Boss ;
- grille de correction détaillée ;
- secrets, clés SSH, mots de passe, IP ou données d'un environnement réel.

## Vérification avant Pull Request

```bash
make syntax
```

Les scripts shell doivent rester compatibles Bash sur Ubuntu Server 24.04 LTS.
