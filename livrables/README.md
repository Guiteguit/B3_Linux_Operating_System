# Livrables locaux

Ce dossier est destiné aux fichiers produits pendant les TPs.

Il est **ignoré par Git par défaut** pour éviter de publier :

- les réponses aux exercices ;
- des adresses IP propres au lab ;
- des clés, secrets ou informations système ;
- des fichiers de sauvegarde volumineux.

Structure conseillée :

```text
livrables/
├── tp00.txt
├── tp01.txt
├── tp02.txt
├── tp03.txt
├── tp04.txt
├── tp05.txt
├── tp06/
├── tp07.txt
├── tp08/
└── tp09-incident.md
```

Pour une remise via GitHub Classroom, le formateur peut modifier `.gitignore` ou demander un dépôt privé individuel.
