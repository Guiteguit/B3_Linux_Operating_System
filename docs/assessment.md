# Évaluation indicative

| Élément | Pondération |
|---|---:|
| Progression et validations TP | 30 % |
| QCM / écrit | 20 % |
| Final Boss — diagnostic et correction | 40 % |
| Explication individuelle / mini-RCA | 10 % |

## Ce qui est réellement évalué

Une commande correcte n'est pas suffisante. L'étudiant doit pouvoir expliquer :

- le symptôme observé ;
- la source utilisée pour confirmer son hypothèse ;
- pourquoi la correction choisie est adaptée ;
- comment il a validé l'absence de régression.

## Final Boss

Le TP09 valorise particulièrement la méthode :

```text
Observation → faits → hypothèse → test → correction minimale → validation → RCA
```

Une réinstallation du serveur ne constitue pas une résolution acceptable de l'incident.
